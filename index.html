    Process

    How a project moves when I run it. The same four stages, whether it is a two-week feature or a year-long platform.

    1. 1

      Discovery

      Sit with the client and the team until the problem is written down in one paragraph everyone signs off on.

    2. 2

      Planning

      Scope, estimates and risks, documented the CMMI way, so nobody has to guess what “done” means.

    3. 3

      Delivery

      Short iterations, honest status reports, and a developer’s eye on the blockers before they become delays.

    4. 4

      Review

      Measure against the plan, run the retro, and feed what we learned into the next project.
